# 🚀 Planify – Responsive Product Pricing Cards

A modern, responsive SaaS pricing webpage built using **HTML, CSS, and JavaScript**. Planify helps users compare subscription plans through an interactive pricing interface with monthly and yearly billing options.

## 🌐 Live Demo

[View Planify Live](YOUR_GITHUB_PAGES_URL)

## 📌 Project Overview

Planify is a frontend web development project featuring three subscription plans: Starter, Professional, and Enterprise.

The website provides a clean pricing comparison experience with interactive billing options, automatic yearly savings calculations, attractive pricing cards, and responsive layouts for different screen sizes.

## ✨ Features

- **Three Pricing Plans:** Starter, Professional, and Enterprise.
- **Monthly/Yearly Toggle:** Switch between monthly and yearly subscription prices.
- **Automatic Savings Calculation:** Displays annual savings when yearly billing is selected.
- **Popular Plan Badge:** Highlights the Professional plan.
- **Best Value Badge:** Identifies the recommended subscription plan.
- **Interactive CTA Buttons:** Opens a confirmation dialog when a plan is selected.
- **Hover Effects:** Smooth card animations and visual transitions.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Accessibility:** Keyboard navigation, visible focus indicators, and reduced-motion support.
